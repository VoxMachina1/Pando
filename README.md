# Pando — a front-end for curated video corpora

YouTube's front page is a recommendation algorithm. This is the
opposite: a static, login-free front-end whose entire catalogue is a
**fixed corpus you choose** — a list of videos from curators you
trust. No feed, no autoplay-into-the-void, no account. State (liked,
watch-later, history, playlists) lives in the browser and nowhere else.

One front-end, any corpus. A corpus is a GitHub repository holding a
`corpus.json`. Point the page at one and it becomes that curator's
tube:

```
index.html?corpus=github-user/repo-name
```

*Why Pando: the Utah aspen colony of that name is thousands of
trunks growing from a single root system — one organism. Pando the
front-end is the root system; every corpus pointed at it is another
trunk.*

## Quick start

Full walkthrough: [SETUP.md](SETUP.md) — going live on GitHub
Pages, switching topics, and building your own corpus.

- **Just open it**: `index.html` next to a `corpus.json` renders that
  corpus. The corpus in this repo is an AI-education starter.
- **Host it anywhere static**: GitHub Pages, Netlify, a home server,
  a USB stick. It is one HTML file; `corpus.json` is data.
- **Make your own corpus**: see [CORPUS.md](CORPUS.md). The minimal
  corpus is a JSON list of YouTube links. The full form — channels,
  categories, durations, view counts — is generated by
  `tools/build_corpus.py` from a channel list (yt-dlp, identity-
  verified handles, top-N by views).

## Features

- Category chips, channel filter, full-text search, sorts
  (most viewed / **newest first** / longest / A–Z / shuffle), a
  Longs view (20m+). Newest first uses each video's `published`
  date (shown on the card as Mon YYYY); undated videos sort last
- Liked / Watch later / History, stored locally only
- **Playlists**: create your own lists, add videos from any card or
  the player, reorder or remove entries, rename/delete lists.
  Playlists persist in the browser, per corpus. Play all or shuffle
  play; a playlist auto-advances in normal browsing (optional loop),
  with an "Up next" line in the player
- **Autoplay toggle** in the player: roll through whatever list is
  on screen, YouTube-style, without entering TV mode
- **TV mode**: lean-back autoplay through the current list, with
  keyboard controls (space, N/P, arrows, 0–9 seek, M mute)
- **Honest framing**: what you see is the whole corpus, with its
  size and total hours printed at the top — curation you can audit

## Why

Built after Karpathy's HackerTube/TristanTube showed the pattern:
mine a curation signal you trust, publish the dataset, and let the
front-end be a thin, honest window over it. This implementation
generalises it — the corpus lives in a GitHub repo, so corpora are
forkable, diffable and shareable like awesome-lists, and the player
is the same for all of them.

## Provenance of the starter corpus

Seeded from Tristan Hume's 2026 YouTube tier list (the list behind
TristanTube), filtered to its AI/ML-education slice and extended
with the established AI-education canon (Karpathy, 3Blue1Brown,
StatQuest, DeepLearning.AI, MIT OpenCourseWare — title-filtered to
AI/ML — and others). A **Hardware & Homelab** category (Level1Techs,
ServeTheHome, Craft Computing, Jeff Geerling, Hardware Unboxed and
friends, drawn from the r/homelab community canon) was added the
same day. Per channel: the 30 most-watched videos, enumerated
2026-11-07 — 33 channels, 973 videos. Handles were
identity-verified at build time (several famous handles turned out
to belong to namesakes — including ServeTheHome, whose real handle
is @ServeTheHomeVideo). Upload dates were fetched per video for
the newest-first sort; 949 of 973 carry one. Two channels were cut
entirely after the first build for drifting off the corpus's
education standard: GamersNexus (too news-driven) and Lex Fridman
(long-form interviews, not teaching).
